Возможности

Всё, что нужно абитуриенту в одном месте — от подбора программ до отслеживания заявок.

01

Каталог вузов

Университеты, факультеты и программы с поиском, фильтрами и карточками направлений.

02

Экзамены

Наборы ЕГЭ и вступительных испытаний по каждой программе и форме обучения.

03

Заявления

Подача заявок и отслеживание статусов в личном кабинете с древом заявок.

04

Рекомендации

Подбор программ под профиль, баллы, экзамены и предпочтения пользователя.

05

Сравнение программ

Сопоставление направлений по ключевым параметрам: баллы, экзамены, стоимость.

06

Свайпер вузов

Быстрый выбор вуза в формате свайпов с карточками и направлениями.

07

Личный кабинет

Профиль, дипломы и достижения, образовательные документы и история заявок.

08

ИИ-чат

Консультация по поступлению: стриминговые ответы с поддержкой Markdown.

09

Админ-панель

Управление справочниками, материалами, пользователями и заявками.

Технологии

Монорепозиторий: асинхронный backend, современный frontend и reverse-proxy.

Backend

  • FastAPI
  • SQLAlchemy 2.0 (async)
  • PostgreSQL + asyncpg
  • Pydantic v2
  • Alembic
  • JWT + argon2 (pwdlib)

Frontend

  • Next.js (App Router)
  • React 19
  • TypeScript 5
  • Tailwind CSS 4
  • framer-motion
  • bun

Инфраструктура

  • Docker Compose
  • nginx (reverse-proxy)
  • AI-прокси (streaming)
  • Redis

Запуск

Всё вместе — база данных, backend, фронтенд и nginx.

docker compose build
docker compose up -d

Сайт: http://localhost · API и Swagger: /api · Health: /health. Сервис миграций применяет схему и демо-данные при первом старте.
