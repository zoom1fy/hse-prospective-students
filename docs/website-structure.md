# Техническое задание: Сервис наглядного информирования о поступлении

## 1. Вводные положения и цели
* **Контекст:** Отсутствует необходимость повторно реализовывать функционал подачи документов (аналог Госуслуг).
* **Основная цель:** Предоставить пользователю максимально наглядную информацию о процессе поступления.

---

## 2. Анализ ограничений текущего решения (Госуслуги)
1. При выборе ВУЗа, факультета или направления выбор фиксируется как факт: отсутствует возможность перехода на сайт ВУЗа или просмотра сводной информации.
2. В имеющемся функционале подбора программ (по ВУЗу, региону, уровню образования) отсутствует автоматическая выдача рекомендаций (например, вывод ТОП-3 вариантов сразу после заполнения личного кабинета).
3. Просмотр заявлений реализован в виде списка по последним действиям (с возможностью фильтрации по конкретному ВУЗу), где вся информация отображается сплошным текстом, что затрудняет восприятие.
   * **Решение:** Секция просмотра заявлений реализуется в виде древовидной структуры:
     * **Корень:** ВУЗ
     * **Второй уровень:** Факультет
     * **Третий уровень:** Программа
   * Для каждого элемента дерева обеспечивается переход на соответствующий сайт (ВУЗа, факультета, программы) и отображается статус ветки.

---

## 3. Структура и функциональные требования к страницам

### Страница 1. Главная (Home)
* **Функциональные возможности:**
  1. Просмотр ведущих университетов.
  2. Просмотр популярных направлений.
  3. Просмотр открытых наборов на программы.
  4. Поиск ВУЗов и программ с использованием фильтров.
* **Точки перехода:**
  1. Личный кабинет.
  2. Сайт конкретного ВУЗа.
  3. Сайт программы (в том числе через сайт ВУЗа).

---

### Страница 2. Личный кабинет
* **Функциональные возможности:**
  1. Просмотр и заполнение персональных данных:
     1. ФИО и контакты (email)
     2. Документ об образовании / диплом (добавление через модальное окно)
     3. Достижения
     4. Другое образование
  2. Автоматический подбор программ по введенным критериям непосредственно из личного кабинета (выдача рекомендаций на основе введенных данных без необходимости ручного поиска среди всех программ).

---

### Страница 3. Интеграция с сайтами ВУЗов / программ
* При клике на наименование ВУЗа (например, НИУ ВШЭ) выполняется переход на официальный сайт ВУЗа.
* При клике на наименование программы (например, "Программная инженерия" НИУ ВШЭ) выполняется переход на страницу соответствующей программы.

---

### Страница 4. Древо подачи заявок
* **Назначение:** Наглядное отображение отправленных заявок взамен табличного формата.
* **Структура отображения:** Древовидный граф/список:
  * **Корень:** Университет
  * **Следующий уровень:** Факультет
  * **Следующий уровень:** Программа
* **Интерактивность:** При нажатии на любой элемент дерева осуществляется переход на страницу с подробной информацией.

---

### Страница 5. Админ-панель
* **Доступ:** только пользователи с ролью администратора (`users.is_admin`).
* **Функциональные возможности:**
  1. Обзор: сводная статистика по пользователям, вузам, программам, заявкам и материалам.
  2. Пользователи: поиск, редактирование профиля, выдача/снятие прав администратора, удаление.
  3. Университеты и факультеты: создание, редактирование и удаление.
  4. Программы: создание, редактирование, удаление, фильтры по вузу.
  5. Заявки: список всех заявлений и смена статуса.
  6. Материалы: публикация статей и гайдов (черновики и разделы содержимого).
