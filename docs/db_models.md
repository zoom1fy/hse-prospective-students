# ОСНОВНЫЕ ТАБЛИЦЫ

**users** - абитуриенты
Поля:
    1. **first_name, last_name, patronymic** - ФИО абитуриента
    2. **email, education** - контакт и сведения об образовании абитуриента
    3. **password_hash** - хеш пароля (argon2), сам пароль не хранится
    4. **id_region** - id региона где он живет


**universities** - университеты
Поля:
    1. **name, email, short_name, description** - данные университета
    2. **official_url** - ссылка на сайт университета
    3. **logo** - ссылка на картинку университета
    4. **id_region** - id региона где находится университет

**faculties** - факультеты в университетах
Поля:
    1. **name, short_name** - данные факультета
    2. **official_url** - ссылка на сайт факультета
    3. **id_university** - id университета в котором находится факультет


**programs** - программы в факультетах
Поля:
    1. **name, code, description** - данные программы
    2. **duration_years, budget_places, paid_places, tuition_price** - срок обучения, кол-во бюджетных мест, кол-во платных мест, стоимость обучения (год)
    3 **id_type_study, id_edication_level, id_faculty** - тип обучения, уровень образования, id факультета в котором находится программа

**exams** - экзамены ЕГЭ
Поля:
    1. **name** - название экзамена

# ВСПОМОГАТЕЛЬНЫЕ ТАБЛИЦЫ

**achievement_categories** - категории достижения у абитуриентов
Поля:
    1. **name** - название категории

**achievement** - достижения у абитуриентов
Поля:
    1. **name** - название достижения
    2. **id_user, id_category** - id абитуриента и id категории достижения

**diploma_types** - типы документов об образовании (аттестат, бакалавриат, специалитет, магистратура, аспирантура)
Поля:
    1. **name** - название типа

**diplomas** - документы об образовании абитуриентов
Поля:
    1. **name, institution, year** - название документа, учебное заведение и год получения
    2. **average_score** - средний балл (может быть не указан)
    3. **id_user, id_diploma_type** - id абитуриента и id типа документа

**type_study** - тип обучения (очно, заочно, очно-заочно)

**education_level** - степень образования (магистратура, бакалавриат, специалитет, аспирантура)

**regions** - таблица разных регионов (для университетов и абитуриентов)

**statement_statuses** - статусы заявлений на поступление (только название статусов)

# СВЯЗУЮЩИЕ ТАБЛИЦЫ 

**statement** - таблица заявлений абитуриентов на программы
Соединение: 1 ко многим, один абитуриент подает заявление на несколько программ, у каждого заявления свой статус. По этой таблице формируется древо-граф заявлений.

**user_programs** - таблица избранных абитуриентом программ (он сам их выбрал для себя)
Соединение: 1 ко многим, один абитуриент выбрал для себя несколько программ

**recommendation_program_user** - таблица рекомендованных программ абитуриенту (программы подобрала ии на основе данных абитуриента) 
Соединение: 1 ко многим, одному абитуриенту рекомендовано несколько программ. Эта таблица формируется по данным абитуриента ИИ

**program_exam** - таблица необходимых экзаменов для программы
Соединения: 1 ко многим, для одной программы надо сдать несколько экзаменов. В таблице есть поле **passing_score** - это проходной балл по экзамену.

**user_exam** - таблица экзаменов, которые сдал абитуриент
Соединения: 1 ко многим, один абитуриент сдал несколько экзаменов. В таблице есть поле **score_achieved** - это сколько набрал абитуриент баллов по своему экзамену

**comparisons** - таблица где абитуриент сравнил две программы
Соединения: 1 ко многим (не правильно сделано), один пользователь выбирает 2 программы для сравнения. В таблице есть поле **explanation** - это вердик от ИИ, какая программа лучше.

Более подробно

Абитуриент зашел на страницу сравнения (или в панели отдельной) и выбрал две программы. После нажатия на кнопкуу сравнить данные абитуриента и программ уходят ИИ, которая сравнивает и пишет вердикт - какая программа абитуриенту подходит больше. В таблице есть поле top_program - это просто идентификатор для того, чтобы понять какую программу выбрала ИИ (т.е. ии написала, что вторая программа лучше и отправила вместе с текстом цифру 2, после происходит запись в таблицу, а на Front обновляется и таблицу 2 обводит зеленым, как пример). Если это можно реализовать по другому, то данное поле можно вообще удалить
